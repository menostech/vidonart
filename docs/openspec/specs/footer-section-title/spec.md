## Requirements

### Requirement: Footer link-section title typography
The system SHALL render the footer link-section headings (Information / Customer Service / Extras / My Account) at the same font size as the section links below them and in bold, so the heading hierarchy is clearly distinguishable from the links.

#### Scenario: Footer section titles match link size and are bold
- **WHEN** a shopper loads any storefront page with footer link sections
- **THEN** each section heading renders at the same font size as the links in that section and with a bold font weight
